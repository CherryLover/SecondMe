## 功能概述

在 SecondMe 中集成完整的任务管理功能，支持基础任务管理、子任务、对话操作（后续版本）、外部 API 调用。

## 核心特性

### 1. 基础任务管理
- 任务 CRUD（创建、读取、更新、删除）
- 任务属性：标题、描述、状态、优先级（1-5）、分组、截止日期
- 状态流转：pending → in_progress → completed/cancelled
- 分组管理：用户自由输入，支持自动补全

### 2. 子任务支持
- 最多 2 层嵌套（任务 → 子任务）
- 子任务可提升为独立任务
- 无子任务的任务可转为子任务
- 限制：有子任务的任务不能转为子任务
- 主任务完成时，所有子任务自动完成

### 3. API Token 系统
- 用户可创建多个永久有效的 API Token
- 每个 Token 可自定义名称（如"我的 iOS App"）
- Token 支持访问所有用户数据（除管理员端点）
- Token 格式：`smt_` 前缀 + 32 字节随机字符串

### 4. UI 集成
- 对话页面右侧固定显示 TODO 列表
- 支持筛选（按状态、分组）、排序（优先级、截止日期）
- 快速添加、编辑、删除、完成任务
- 子任务嵌套显示
- SettingsPage 新增 API Tokens 管理标签页

## 数据库变更

### 新增表

**todos 表：**
```sql
CREATE TABLE todos (
    id INTEGER PRIMARY KEY AUTOINCREMENT,
    user_id INTEGER NOT NULL,
    parent_id INTEGER NULL,
    title TEXT NOT NULL,
    description TEXT NULL,
    status TEXT NOT NULL DEFAULT 'pending',
    priority INTEGER DEFAULT 3,
    group_name TEXT NULL,
    deadline TIMESTAMP NULL,
    completed_at TIMESTAMP NULL,
    created_at TIMESTAMP NOT NULL,
    updated_at TIMESTAMP NOT NULL,
    FOREIGN KEY (user_id) REFERENCES users(id) ON DELETE CASCADE,
    FOREIGN KEY (parent_id) REFERENCES todos(id) ON DELETE CASCADE
);

CREATE INDEX idx_todos_user_id ON todos(user_id);
CREATE INDEX idx_todos_parent_id ON todos(parent_id);
CREATE INDEX idx_todos_user_status ON todos(user_id, status);
CREATE INDEX idx_todos_deadline ON todos(deadline) WHERE deadline IS NOT NULL;
```

**api_tokens 表：**
```sql
CREATE TABLE api_tokens (
    id INTEGER PRIMARY KEY AUTOINCREMENT,
    user_id INTEGER NOT NULL,
    name TEXT NOT NULL,
    token TEXT NOT NULL UNIQUE,
    created_at TIMESTAMP NOT NULL,
    last_used_at TIMESTAMP NULL,
    FOREIGN KEY (user_id) REFERENCES users(id) ON DELETE CASCADE
);

CREATE UNIQUE INDEX idx_api_tokens_token ON api_tokens(token);
CREATE INDEX idx_api_tokens_user_id ON api_tokens(user_id);
```

## 注意事项

1. **数据隔离**：所有 TODO 数据按 user_id 严格隔离
2. **层级限制**：子任务最多 2 层，需在 update_todo 时验证
3. **级联删除**：删除任务时自动删除所有子任务
4. **API Token 安全**：Token 只在创建时返回一次完整内容
5. **兼容性**：API Token 和 JWT 共存，不影响现有功能
