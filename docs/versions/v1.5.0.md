## 功能概述

将 SecondMe 改造为 PWA（Progressive Web App），支持：
- 添加到主屏幕
- 独立窗口运行
- 离线打开应用
- 静态资源缓存
- 后台自动更新

## 技术要点

### Vite PWA 配置
```typescript
VitePWA({
  registerType: 'autoUpdate',  // 后台自动更新
  manifest: {
    name: 'Evera · 常在',
    short_name: 'Evera',
    theme_color: '#000000',
    display: 'standalone'
  },
  workbox: {
    globPatterns: ['**/*.{js,css,html,ico,png,svg,woff,woff2}']
  }
})
```

### 缓存策略
- 静态资源：CacheFirst（缓存优先）
- HTML 文档：NetworkFirst（网络优先）
- API 请求：NetworkOnly（仅网络，不缓存）

### 更新机制
- 用户打开应用时后台检查更新
- 有新版本时后台下载
- 下次打开自动使用新版本
- 无弹窗打扰

## 测试步骤

### 本地测试
```bash
cd web
npm run build
npm run preview
```

### 测试项
1. **安装测试**
   - 浏览器地址栏显示安装图标
   - 点击安装，应用添加到桌面
   - 独立窗口打开（无地址栏）

2. **离线测试**
   - 首次访问后，开启飞行模式
   - 刷新或重新打开应用
   - 应用能打开，显示页面
   - API 请求失败显示错误

3. **缓存测试**
   - 查看 DevTools → Application → Cache Storage
   - 确认静态资源已缓存
   - 离线时从缓存加载

4. **更新测试**
   - 修改代码重新构建
   - 后台自动下载更新
   - 关闭重开，新版本生效

## 注意事项

1. **HTTPS 要求**: Service Worker 需要 HTTPS（localhost 除外）
2. **浏览器兼容**: 现代浏览器均支持，Safari 需 11.3+
3. **测试环境**: 必须用生产构建测试（`npm run preview`）
4. **图标格式**: PNG 格式，背景透明或纯色
5. **主题色**: 可根据实际设计调整
