### TODO 任务管理系统
- **状态**：🚧 开发中
- **提出时间**：2026-01-14
- **版本**：v2.0.0
- **设计文档**：[13-TODO任务管理系统设计.md](./13-TODO任务管理系统设计.md)
- **版本详情**：[versions/v2.0.0.md](./versions/v2.0.0.md)
- **简述**：完整的任务管理功能，支持对话操作和外部 API 调用
- **核心功能**：
  - 基础任务管理：分组（可选）、优先级（1-5）、截止日期、状态（pending/in_progress/completed/cancelled）、备注
  - 子任务支持：最多 2 层嵌套，支持灵活的父子关系转换
  - 对话中操作：通过自然语言理解用户意图，AI 辅助操作任务（v2.1.0 实现）
  - 外部 API：永久有效的 API Token 系统，支持第三方应用调用
  - UI 集成：对话页面右侧固定显示 TODO 列表
