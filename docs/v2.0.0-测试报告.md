### 新增表结构

**todos 表**:
```sql
- id (TEXT PRIMARY KEY)
- user_id (TEXT NOT NULL)
- parent_id (TEXT)
- title (TEXT NOT NULL)
- description (TEXT)
- status (TEXT NOT NULL, CHECK)
- priority (INTEGER, CHECK 1-5)
- group_name (TEXT)
- deadline (TEXT)
- completed_at (TEXT)
- created_at (TEXT)
- updated_at (TEXT)
```

**api_tokens 表**:
```sql
- id (TEXT PRIMARY KEY)
- user_id (TEXT NOT NULL)
- name (TEXT NOT NULL)
- token_hash (TEXT NOT NULL UNIQUE)
- token_preview (TEXT NOT NULL)
- created_at (TEXT)
- last_used_at (TEXT)
```
